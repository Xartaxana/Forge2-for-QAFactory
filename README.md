Status: empty repository, created 2026-11-25 on the owner's word. Nothing is built here yet.

## What will live here

- **The light factory** -- the QA factory rebuilt: work goes in stages, each stage in a fresh context with its own
  craft page; one story record is the only handoff form between stages; a gate at the exit of each stage does not
  hinder the performer inside the stage and does not let unfinished work pass.
- **Forge 2** -- the tooling and rules that build the light factory.

## Yardstick

The factory does everything a free agent with one prompt would do, and more: better and more predictably. A factory
that does less than a free agent is working wrong.
